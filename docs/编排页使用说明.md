# 编排页使用说明（脚本制作 → 编排）

> 状态：已实现（2026-09-09 晚更新）。页面 = `Views/EditorPage.xaml` 的「编排」标签页
> （`MainTabs.SelectedIndex == 0`），逻辑在 `Views/EditorPage.xaml.cs`。
> 布局：左侧动作库 → 中间 3D 预览 → 右侧段参数，底部是整条时间轴。

## 1. 工具栏

| 按钮 | 控件 / 入口 | 说明 |
|---|---|---|
| 新建 | `ComposeNew_Click` | 清空当前合成；有未保存改动先走 `ConfirmDiscardChanges` |
| 打开 | `ComposeOpen_Click` / `ComposeOpen_Executed` | 默认打开 `CompositionStore.EnsureDirectory()` 目录下的 `.json`；快捷键 Ctrl+O |
| 保存 | `ComposeSave_Click` | 见第 6 节 |
| 另存为 | `ComposeSaveAs_Click` | 弹保存对话框，写盘统一走 `WriteComposition` |
| ↶ 撤销 | `ComposeUndoBtn` / `ComposeUndo_Click` | 仅编排页；栈空时禁用 |
| ↷ 重做 | `ComposeRedoBtn` / `ComposeRedo_Click` | 同上 |
| 导入 funscript | `ComposeImport_Click` | 导入落到「微调波形」页（编排页无法反向拆成动作段）；误选到合成 `.json` 会自动当合成打开 |
| 导出 funscript | `ComposeExport_Click` | 按时间轴顺序采样，单文件含 L0..R2 六轴，默认写到脚本库目录 |
| ▶ 播放 / ⏹ 停止 | `ComposePlay_Click` / `ComposeStop_Click` | 见第 4 节 |
| BPM | `ComposeBpmSlider` + `ComposeBpmLabel` | 10–240（`ScriptComposerService.MinBpm/MaxBpm`），60 = 每秒一圈；只改快慢，不改总时长 |

### 撤销 / 重做（本轮新增）

- 编排页有自己一套独立栈：`_composeUndoStack` / `_composeRedoStack`
  （元素类型 `ComposeUndoSnapshot`，是「整个合成深拷贝 + 当时选中段下标 + 操作标签」），
  **与微调波形页的 `_undoStacks` / `_redoStacks` 完全分开**，互不影响。
- 快捷键 **Ctrl+Z / Ctrl+Y** 由 `ComposeUndo_PreviewKeyDown` 处理：只在
  `MainTabs.SelectedIndex == 0` 且页面可见时生效；焦点在输入框里时让给文本框自身的文字撤销
  （不抢）。微调波形页仍走 `Undo_Executed` / `Redo_Executed`——它们在编排页直接 return。
- 栈上限 `MaxComposeUndoSteps = 100`（`PushComposeUndoCore` / `ComposeUndo` / `ComposeRedo`
  超限时 `RemoveAt(0)`）。
- 连续型改动（拖段时长 / 强度 / 过渡滑块、拖卡片右边缘）走 `PushComposeUndoCoalesced`：
  同一个 label 的连续事件间隔小于 `ComposeUndoCoalesceMs = 300ms` 只压一次栈，
  **一次拖拽 = 一个撤销步**；离散操作（添加 / 删除 / 复制 / 移动 / 排序）走 `PushComposeUndo`，
  会打断合并窗口。段时长输入框另有 `PushComposeUndoForDurationBox`：值没变不压栈。
- 撤销 / 重做恢复时会 `ComposeStopPlayback()` 并重建时间轴卡片
  （`CaptureComposeSnapshot` / `ApplyComposeSnapshot`）；撤销后焦点被踢出页面时会补回
  `MainTabs`，连续按 Ctrl+Z 不失效。

## 2. 时间轴缩放

- 右上角「缩放」滑块 `TimelineZoomSlider`：**8–160 px/秒，默认 40**
  （`TimelineZoomMin/Max/Default`，字段 `_timelineZoom`，属性 `PxPerSecond` 会夹取）。
- 「复位」按钮 `TimelineZoomReset_Click` 把滑块恢复成 40 px/s。
- 缩放变化走 `TimelineZoomSlider_ValueChanged` → `ApplyTimelineZoom()`：重排卡片宽度、重画标尺、
  重定位播放头，**不重建可视化树**（选中态保留）。
- 标尺刻度步长由 `PickRulerStep` 从候选 `{0.25, 0.5, 1, 2, 5, 10, 15, 30, 60, 120, 300}`
  里挑第一个满足「相邻标签至少 `RulerMinLabelGap = 46px`」的步长，
  **自动挑步长保证标签不重叠**；次刻度只画短线不写字（`DrawTimelineRuler`）。
- 所有「时间 ↔ 像素」换算统一走 `PxPerSecond` / `SegmentWidthFor` / `TimelineX` /
  `SecondsAtTimelineX`：卡片宽度、标尺、播放头、点击定位、拖拽插入、自动跟随滚动共用同一套。
  注意 `ScriptComposerService.PixelsPerSecond` 是服务层常量（导出与其它页面在用），页面不修改它。

## 3. 段操作

| 操作 | 实现 |
|---|---|
| 从左侧动作库拖入 | 拖拽数据格式 `LibraryDragFormat`（动作 Id）：`Library_PreviewMouseMove` → `Timeline_Drop` |
| 双击动作库条目添加 | `ComposeLibraryList_MouseDoubleClick` → `AppendComposeSegment`（追加到末尾） |
| 「＋ 添加」按钮 | `ComposeLibraryAdd_Click` → `AppendComposeSegment` |
| 点击选中 | `SegmentCard_Click`（重建卡片，选中段描边用 Accent） |
| 右键菜单 | `BuildSegmentCard` 里的 `ContextMenu`：**复制该段 / 删除 / 前移 / 后移** |
| Del 删除选中段 | `WireComposeControls` 里的 `PreviewKeyDown`：`Key.Delete` 且焦点不在文本框时 `RemoveSegment(_selectedSegment)` |
| 拖右边缘改时长 | 右边缘 `Thumb`（`Width = 6`，`Style = HexaResizeThumb`）→ `SegmentResize_DragDelta` |
| 拖卡片主体重新排序 | `SegmentCard_ReorderMouseDown` → `SegmentPanel_ReorderMouseMove` → `ApplySegmentReorder` |

**拖拽排序的细节（本轮新增）**：在卡片主体按住左键、移动超过系统拖拽阈值
（`SystemParameters.MinimumHorizontal/VerticalDragDistance`）才进入排序，只点一下仍是选中；
拖动时被拖卡片 `Opacity = SegmentDragOpacity = 0.45`（半透明），并在 `TimelineOverlay` 里
显示一条 2px 插入位置指示线（`ShowReorderIndicator` / `UpdateReorderIndicator` /
`ReorderIndicatorX`）；松手 `ApplySegmentReorder` 把段移到目标位置并
`PushComposeUndo("拖拽排序")`。命中右边缘 8px 的 `Thumb` 时
`SegmentCard_ReorderMouseDown` 直接 return，两种拖拽互不抢——
**右边缘那条手柄（视觉 4px、命中 8px）仍然只管改时长，不参与排序**。

## 4. 播放

- **从当前预览位置起播**：`ComposePlay_Click` 取 `from = _previewSeconds`（若已在末尾 0.01s
  以内则从头）。点过时间轴空白处定位后（`TimelineHost_MouseLeftButtonDown` 会写
  `_previewSeconds` 与 `_playheadOffset`），按播放不会跳回 0。
- **播放中改段时长 / 强度实时生效**：`ComposeTick` 每帧比对 `ComposeSignature()`
  （时长 / 强度 / 过渡 / 动作指纹）；检测到变化时调 `RebasePlayheadAfterEdit`，
  把播放头重新锚定到**同一段的同一进度**（`_playAnchorSegment` + `_playAnchorProgress`），
  不会跳到别的段；同时设 `_composeEditHintTicks = 50`（约 2s）。
- 预览标签 `ComposePreviewLabel` 会短暂显示「· 改动已实时生效」（`EditHintSuffix`）。
- **播到结尾自动停**：`ComposeTick` 里 `seconds >= total` 时 `ComposeStopPlayback()`，
  不循环（避免设备在无人看管时一直动）。
- 「同步驱动设备」`ComposeDriveCheck` 勾选状态持久化到 `AppSettings.ScriptDriveDevice`；
  未连接 / 急停 / 被其它模式占用时只做 3D 预览并明确提示（`ComposePlay_Click`）。
- 播放时时间轴会自动跟随播放头横向滚动（`FollowPlayhead`）。

## 5. 打开 / 新建与「继续上次编辑」

- **打开**（`LoadCompositionFromPath`）和**新建**（`ComposeNew_Click`）都会调
  `ClearComposeUndoHistory()`，避免 Ctrl+Z 把旧合成撤回来。
- 打开成功后写 `App.Settings.LastCompositionPath = path` 并 `Save()`。
- 启动后第一次进编排页，`OfferLastCompositionOnce()` 会提示
  「继续上次编辑的合成「X」？」——依据就是 `App.Settings.LastCompositionPath`；
  当前已有内容或未保存改动时不打扰。

## 6. 保存位置

- 默认目录 `%LOCALAPPDATA%\Hexa\compositions\<名字>.json`
  （`CompositionStore.DefaultDirectoryPath` / `DirectoryPath` / `PathFor`）。
- 设置页「存储位置 → 动作合成目录」可改：`SettingsPage` 的
  `CompositionFolderBrowse_Click` / `CompositionFolderReset_Click` / `ApplyStorageFolder`
  写 `App.Settings.CompositionFolder` + `CompositionStore.CustomDirectory`，立即生效并落盘；
  「恢复默认」= 清空该设置。
- **从库外打开的合成点「保存」会写回原文件**：`SaveComposition` 判断
  `outsideLibrary` 且名字没变时直接 `WriteComposition(current)`，
  不再悄悄在 compositions 目录另存一份。
- 覆盖 compositions 目录里已存在的同名合成前会确认（`SaveComposition`）。

## 7. 失效段提示

- 动作库里已不存在的动作（`ScriptComposerService.FindPreset` 返回 null）在导出时会
  **跳过该段**，但会 `cursor += duration` 保留时间轴时长、保证后续段不错位
  （`ScriptComposerService.ComposeFunscript`）。
- 底部提示 `ComposeHintLabel` 由 `UpdateComposeTotals` 维护：
  `missing = 段数 − resolvable`，`missing > 0` 时显示
  「有 N 段的动作在动作库里已不存在，导出时会跳过这些段（时间轴仍保留其时长）。」
  选中段的参数面板 `SegPresetLabel` 也会标注该段动作已不存在。
- 若全部段都失效，导出抛 `InvalidOperationException("合成里的动作在动作库中都不存在，无法导出。")`，
  由 `ComposeExport_Click` 弹错误框。
