# 微调波形（手画波形）使用说明

> 状态：已按 2026-09-10 深度测评报告优化。页面 = `Views/EditorPage.xaml` 的「微调波形」标签页
> （`MainTabs.SelectedIndex == 1`），逻辑在 `Views/EditorPage.xaml.cs`。
> 测评原文见 `../_wave_editor_review.md`（25 条），本页只写「现在怎么用 / 和以前有什么不同」。

## 一、画布

- **等比缩放**：画布按 650×240 的模型坐标等比缩放并居中（`Scale = min(宽/650, 高/240)`）。
  以前 X/Y 各自缩放，小窗口下正弦被压扁、最大化又被拉长；现在形状始终正确。
- **加点**：左键点空白处加一个控制点。若该位置已经有同 X 的点，会**替换**它并在状态行提示，不再静默产生「画面上两个点、实际只有一个」。
- **拖动**：按住控制点拖动。超过系统拖拽阈值才算拖动（避免「点一下」就留下一个撤销步），
  拖动中鼠标被捕获，拖到画布外也不会断；松手才落盘。
- **命中范围**：只命中**当前轴**的点；点其它轴的点不会误往当前轴加点（要编辑别的轴先点轴页签）。
- **删除**：右键点控制点删除。
- **关键帧列表**：点一行可定位并高亮对应点，✕ 删除。六轴总点数超过 300 时只列**当前轴**，
  并显示「其它轴共 N 点（切到对应轴查看）」，避免一次重建几百行卡顿。

## 二、六个轴

- 上排 `L0…R2` 是**编辑轴**（点一下切到该轴）。
- 下排勾选框是**输出轴**：只有勾选的轴才会在「▶ 播放」时驱动设备，未勾选的轴保持中位 50。
- 勾选状态、平滑插值开关会**随草稿和 `.hwp` 预设一起保存**（以前只存波形，重启后六轴全没勾选，
  点播放界面显示「播放中」但设备只输出中位）。
- 给未勾选的轴加点时，状态行会提示「该轴尚未勾选，试跑不会动」。

## 三、播放（试跑）

- 播放前会校验：**至少有一个「已勾选且控制点 ≥2」的轴**，否则直接提示、不会变成「播放中」。
  已勾选但点数不足的轴会在状态行列出（它们会保持中位 50）。
- **离开本页、切到「编排」标签页、最小化到托盘**都会自动停止试跑——以前设备会继续动，
  而停止按钮在被隐藏的标签页里。
- 若「脚本库」正在播放 funscript，试跑前会先把它停掉（否则波形停下后设备会跳到脚本位置）。
- 脚本倍率**只影响试跑速度，不影响导出**；「圈数」只影响导出时长，试跑会一直循环到手动停止。
- 改「周期」会让所有控制点的时间按比例缩放（状态行会提示）。

## 四、导入 / 导出

- **导入 funscript**：先把全部轴解析到临时结构（失败不动内存）→ 列出会被覆盖的轴并确认 →
  每个受影响的轴单独压撤销（可以逐轴 Ctrl+Z）→ 只把导入到的轴设为启用，其它轴关闭并在状态行说明。
  根节点标了 `"inverted": true` 的脚本会按反向导入（位置取 100−pos）。
- **导出**：只有一个轴有数据时，写你选定的文件名；多轴时每轴一个 `名字.轴名.funscript`，
  已存在的派生文件会先列出来确认覆盖；控制点数 <2 的轴跳过并说明；
  成功弹窗列出全部实际路径，并报告「N 个点 → M 个动作，K 个被合并」（重复 X / 同毫秒点不再静默丢）。
- 导出对话框默认目录是「脚本库」目录，导出后到「脚本库」页刷新即可看到。

## 五、撤销 / 重做与状态提示

- 波形工具栏新增「↶ 撤销 / ↷ 重做」按钮（栈空时置灰），Ctrl+Z / Ctrl+Y 同效。
- 撤销按轴独立，上限 50 步，与「编排」页的撤销栈互不影响。
- 画布下方新增**独立状态行**（导入/导出结果、播放失败原因、合并点数、周期变化等），
  6 秒后自动消失；它不会被画布重绘覆盖（以前提示会被下一次重绘擦掉）。

## 六、布局

- 本标签页外层加了纵向滚动：1024×640 这种小窗口下不会再把底部内容裁掉。
- 工具栏与「波形工具 + 导出 + 预设」都用 `WrapPanel`，窄窗口自动换行而不是被裁。
- 关键帧列表限高 160px，窗口变大时多出来的高度给画布（最大化下画布约 490px 高）。

## 附：从音频 / 视频自动生成脚本（脚本库页）

不想手画的话，可以让 Hexa 听一遍你喜欢的音乐或视频，自动写出一份脚本。

**在哪**：脚本库页 →「🎵 从音频生成…」→ 展开面板。

**怎么用**：
1. 「选择文件…」选一个音频（mp3 / wav / m4a / aac / wma）或**视频**（mp4 / mkv / avi / mov，自动取里面的音轨）；
2. 调两个参数：
   - **行程**（10–100%）：动作幅度。100% = 走完全行程，55% = 在中间来回；
   - **灵敏度**（0–2）：越高越容易把弱一点的声音也当成事件；
   - 可选「同时生成扭转轨道（R0，更立体）」；
3. 点「▶ 开始生成」，几秒到几十秒（取决于文件长度），完成后脚本自动存进脚本库，列表里会选中它；
4. 直接「▶ 载入并播放」，或者到「脚本制作 → 微调波形」继续手改。

**它识别什么**：和「声音响应」用的是同一套事件检测 —— **冲击**（爆炸、鼓点重音）走快进快出、
**节拍**走短促跟拍、**渐强**（音乐起伏）走慢而连贯的一个来回；事件之间保持最低位不动。
重音密集的段落会**主动丢弱事件**（宁可少做一个，也不做半截）；动作总数超过上限时同样丢最弱的那些，
并在完成提示里写明丢了多少。

**文件格式**：标准 funscript（多轴时会带 `axes` 里的 R0 轨道），无 BOM UTF-8，
脚本库、微调波形、其它 funscript 播放器都能直接读。
