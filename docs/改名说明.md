# 改名说明：Helix → Hexa

> 2026-09-10。软件定名为 **Hexa**（六轴之意）。
> 原因：原名 `Helix` 与本项目自己依赖的 3D 库 **HelixToolkit** 撞名——IDE 里命名空间、包名、
> 搜索关键词全混在一起；外面还有 Helix 编辑器、Helix 键盘固件等同名软件。
> （改名过程中曾短暂用过 `Spindle` 这个名字，相关目录也会被自动迁移，见第二节。）

## 一、改了哪些地方

| 项目 | 旧 | 新 |
|---|---|---|
| 程序 / 可执行文件 | `Helix.exe` | `Hexa.exe` |
| 程序集 / 根命名空间 | `Helix` | `Hexa` |
| 工程文件 | `Helix.csproj` | `Hexa.csproj` |
| 测试工程 | `tests/Helix.CoreTests` | `tests/Hexa.CoreTests` |
| 数据目录 | `%LOCALAPPDATA%\Helix` | `%LOCALAPPDATA%\Hexa` |
| 单实例互斥名 | `Local\Helix.TCode.Controller.SingleInstance` | `Local\Hexa.TCode.Controller.SingleInstance` |
| 托盘提示 | `Helix — TCode Controller` | `Hexa — TCode Controller` |
| 游戏桥对外设备名 | `Helix OSR6 (L0+R0)` / `Helix Linear (L0)` / `Helix Rotary (R0)` | `Hexa …`（游戏里看到的名字随之变化） |
| 游戏桥服务名 | `Helix OSR6 Bridge` | `Hexa OSR6 Bridge` |
| XAML 资源键 | `HelixTabControl` / `HelixTabItem` / `HelixResizeThumb` | `HexaTabControl` / `HexaTabItem` / `HexaResizeThumb` |
| 调试环境变量 | `HELIX_SETTINGS_PATH` | `HEXA_SETTINGS_PATH` |
| 发布目录 | `dist_helix` | `dist_hexa` |

**没有改**：`HelixToolkit.Wpf` 包与 `HelixViewport3D` 类型（第三方库）、`http://helix-toolkit.org/wpf`
命名空间 URL、SR6 机械模型（osr-emu，MIT）与其它依赖。

## 二、旧数据会自动迁移（不丢）

启动时 `AppSettings.MigrateLegacyDataIfNeeded()`（`Models/AppSettings.cs`）会执行一次迁移，
依次检查 `%LOCALAPPDATA%\Spindle`、`%LOCALAPPDATA%\Helix` 两个旧目录：

- 把 `settings.json`、`presets.json`、`wave-draft.json`、`custom_personas.json` 以及
  `compositions\`、`Scripts\` 目录**复制**到 `%LOCALAPPDATA%\Hexa`；
- **只复制、不删除、不覆盖**：目标已有同名文件就跳过；旧目录原样保留（想清理可自行删除）；
- 迁移结果写进 `app.log`（例：`已从旧数据目录迁移 N 个文件`），失败只记日志、不影响启动。

## 三、需要你手动做的一件事

`Hexa.exe` 是新的可执行文件名，所以：

- 桌面/任务栏**旧的 `Helix.exe` 快捷方式要重新创建**（旧快捷方式会指向已不存在的文件）；
- 如果曾经把 `Helix.exe` 加到开机启动或计划任务，把路径改成 `Hexa.exe`；
- 发布目录从 `dist_helix` 改成 `dist_hexa`（`presets.json` 已一并搬过去，动作预设不会丢）。
